# Ramprasad Avula — professional portfolio

Static, responsive website. Open `index.html` locally to preview; all site assets are in this folder. Fonts load from Google Fonts with local fallbacks.

## Publishing

Create a GitHub repository named `ramoracle.github.io` only if it is not already in use. Upload the CONTENTS of this folder to the repository root. Enable GitHub Pages from the main branch/root. No domain purchase or backend is required for this personal portfolio. Do not overwrite an existing repository without reviewing its contents.

Alternatively use any repository name; its project Pages URL will include that name. All CSS links are relative and work for either layout.

## Before publishing

- Review employment dates, current role, employer spelling and education spelling against your latest records.
- Content combines the supplied resume with hands-on activities confirmed in conversation. Troubleshooting examples are sanitized; no quantified outcomes or certifications have been invented.
- Personal email and mobile number are intentionally visible for recruitment, as requested. Home address, internal URLs/IPs, credentials and confidential logs are omitted.
- The GitHub profile link uses the supplied `ramoracle` account. No LinkedIn URL was supplied, so none is invented.
- Print / save profile as PDF uses the browser print dialog. It is NOT a download of an updated resume PDF. The original resume is not bundled because it does not include these latest highlights.
- This is a local draft, not a deployed website. Review wording before public release.

## Maintenance

Edit `index.html` for content and `style.css` for appearance. Commit with a clear message, such as `Update container deployment experience`. Preview on a phone-sized window and check contact/navigation links before publishing.
